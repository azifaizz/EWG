# Elite Wealth & Growth (EWG)

> **Understand. Guide. Support. Grow.**  
> **INSURE | INVEST | GROW**

Elite Wealth & Growth (EWG) is a modern web application providing expert insurance and loan guidance for individuals, families, and businesses across Tamil Nadu.

## Features

- **Insurance Solutions**: Life, Term, Health, Motor, Travel, and Business insurance advisory.
- **Loan Products**: Personal, Business, Home, and Vehicle loans.
- **Interactive Tools**: EMI Calculator, consultation booking, and customized quotes.
- **Lead Capture**: Streamlined contact and advisory inquiry forms.
- **Responsive Experience**: High-performance, mobile-first design with curated gold and ink aesthetics.

## Technology Stack

- [TanStack Start](https://tanstack.com/start) - Full-stack React framework
- [TanStack Router](https://tanstack.com/router) - Type-safe routing
- [React 19](https://react.dev)
- [Tailwind CSS v4](https://tailwindcss.com)
- [TypeScript](https://www.typescriptlang.org)
- [Vite](https://vite.dev)

## Getting Started

### Prerequisites

- Node.js (v20+ recommended)
- npm or bun

### Installation

```sh
npm install
```

### Development

```sh
npm run dev
```

### Production Build

```sh
npm run build
```
